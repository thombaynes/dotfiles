# Dotfiles review, 15 Nov 2026

Reviewed by Claude on the 2015 MacBook Pro (macOS 12.7, MacPorts, iTerm2). Every item marked
"verified" was checked against this machine, Homebrew's or MacPorts' package index, or by running
the script. Tick items off as they are done.

## 1. Broken today (verified)

- [ ] **Brewfile entries that do not exist** (checked with `brew info`):
      `brew "gotask"` and `cask "go-task"` are both wrong, the formula is `go-task`;
      `cask "graphiql"` is gone; `cask "docker"` was renamed `docker-desktop`;
      `tap "homebrew/bundle"` is obsolete (bundle is built in).

## 3. Robustness and maintainability

- [ ] **`symlink()` in `scripts/functions.sh` does `rm -r` on the destination**, including a
      real directory such as a pre-existing `~/.config/nvim`. Move aside to `*.bak` instead.
- [ ] **Bootstrap order is filesystem order** (`find *`). Use an explicit list so dependencies
      are visible, and add a one-line guard at the top of app-specific scripts
      (`[ -d /Applications/Ghostty.app ] || exit 0` for ghostty, iterm2, vscode, hammerspoon).
      `xcode-select --install` returns before the GUI install finishes, so the success
      message is wrong.
- [ ] **Dead code in `packages/setup.sh`.** The `*.list` loop has nothing to iterate. The
      Portlist header says names are unverified; everything on it except `mas` and
      `terraform-1.17` is installed here and both of those are real ports (`mas @7.0.0`,
      `terraform-1.17 @1.17.2`). Verified names for the commented block: `py313-awscli`,
      `kubectl-1.37`, `postgresql16`/`17`, `fnm` or `nvm` for node.
- [ ] **Fish abbreviations.** `setup` is a generic function name that is easy to collide with.
      Since fish 3.6 abbrs are per-session, so the `abbr -e` loop and `fish -c setup` in
      `fish/setup.sh` do nothing lasting. Idiomatic home: `conf.d/abbreviations.fish`
      (symlink the `conf.d` dir too). Also: every fish file has a `#!/usr/local/bin/fish`
      shebang that is wrong on both machines (drop, or `#!/usr/bin/env fish`); `abbrex` is
      unused and broken under fish 4's `abbr` output format; `emptytrash` clears ASL logs that
      no longer exist; `completions/bundle.fish` and `gem.fish` are 2019 copies shadowing
      fish's built-ins; the universal `fish_user_abbreviations` var in `fish_variables` still
      carries asdf entries (`set -eU fish_user_abbreviations`); mix of
      `set -g fish_user_paths` and `fish_add_path`, pick one.
- [ ] **nvim: `<leader>s` (nearest spec) is a prefix of `<leader>ss` (spell)**, so running the
      nearest spec waits out the 500 ms timeout. Rename one.
- [ ] **nvim, smaller.** `williamboman/mason*` moved to `mason-org/` (redirects today).
      ruby_lsp via mason uses whichever Ruby is on PATH, which can mismatch rbenv-pinned
      projects. Trailing-whitespace autocmd matches `*.*` only: Makefile/Dockerfile skipped,
      Markdown hard line breaks stripped. `init.vim` could be `init.lua`.
- [ ] **tmux nits.** `status-right` spawns `date` every refresh; tmux formats do strftime:
      `set -g status-right " %a, %b %d - %I:%M "`. Reload message says "RELOADEDAD". The
      commented-out copy-mode block is pre-2.4 syntax; modern form:
      `bind -T copy-mode-vi v send -X begin-selection`,
      `bind -T copy-mode-vi y send -X copy-pipe-and-cancel pbcopy` (no reattach-to-user-namespace).
- [ ] **`claude/statusline.sh`** runs jq four times per refresh; one `jq -r '[..] | @tsv'` call
      would do.
- [ ] **README is from 2016.** Ruby-based Homebrew installer, "from the original author" blog
      links, customisation notes pointing at a `[user]` block and a computer name that are no
      longer where it says.
- [ ] **Local cleanup (this machine).** `~/.vimrc` and the three `~/bin` links are dangling.
      `~/.tmux.conf`, `~/.config/nvim`, `~/.hammerspoon/*` and the VS Code link are owned by
      root (something was run with sudo on 14 Nov); the scripts call sudo themselves, so run
      them as the user.
- [ ] **AGENTS.md drift.** `bin/` destination and `bak`; iterm2 row implies the plist is
      installed; hammerspoon row mentions pomodoro.
