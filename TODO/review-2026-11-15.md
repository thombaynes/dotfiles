# Dotfiles review, 15 Nov 2026

Reviewed by Claude on the 2015 MacBook Pro (macOS 12.7, MacPorts, iTerm2). Every item marked
"verified" was checked against this machine, Homebrew's or MacPorts' package index, or by running
the script. Tick items off as they are done.

## 1. Broken today (verified)

- [x] **`bin/setup.sh` never works from bootstrap.** It is the only setup script that does not
      `cd "$(dirname "$0")"` first, so `. ../scripts/functions.sh` fails and sh aborts.
      `~/.local/bin` does not exist; `~/bin` still has dead links to `imgcat`, `sethidden`,
      `togglehidden` from 2021. AGENTS.md still says `~/bin/` and calls `bak` a script.
- [ ] **Every interactive fish shell prints `fish: Unknown command: nodenv`** on this machine.
      Guard both version managers in `fish/config.fish`:
      `command -q nodenv; and nodenv init - | source` (same for rbenv).
- [ ] **Brewfile entries that do not exist** (checked with `brew info`):
      `brew "gotask"` and `cask "go-task"` are both wrong, the formula is `go-task`;
      `cask "graphiql"` is gone; `cask "docker"` was renamed `docker-desktop`;
      `tap "homebrew/bundle"` is obsolete (bundle is built in).
- [x] **tmux plugins never load on this Mac.** `.tmux.conf` ends with
      `run '/opt/homebrew/opt/tpm/share/tpm/tpm'` (hard-coded brew path). Have `tmux/setup.sh`
      clone tpm to `~/.tmux/plugins/tpm` when missing, and use `run '~/.tmux/plugins/tpm/tpm'`
      on both machines. Drop `tpm` from the Brewfile once done.
- [x] **`alias.pull = pull --ff-only` is ignored.** Git never lets an alias shadow a builtin.
      Use `[pull] ff = only` instead.
- [x] **duti never sets `.mp4`.** `duti/org.videolan.vlc` has no trailing newline, so
      `while read` drops the last line. Also `com.jetbrains.intellij` owns 30+ extensions
      (`.md`, `.sh`, `.lua`, ...) but IntelliJ is not in the Brewfile. Decide: add the
      `intellij-idea` cask, or point those at something installed.
- [ ] **`fish/functions/fish_prompt.fish` is fish 2 syntax.** `^/dev/null` is a literal
      argument in fish 4. It is a 2019 copy of the built-in classic prompt. Delete it and use the
      default, or pick one with `fish_config prompt`.
- [ ] **`iterm2/setup.sh` cannot work from bootstrap.** No shebang, no `cd`, so `tic` cannot
      find the terminfo files. The plist in the repo is never installed by anything and differs
      from the live `~/Library/Preferences/com.googlecode.iterm2.plist`. Either install it
      (`defaults import`, or iTerm2 > Settings > "Load preferences from a custom folder")
      or document it as manual.
- [x] **Tree-sitter parsers cannot install here.** nvim-treesitter `main` needs the
      `tree-sitter` CLI. Fixed: the MacPorts port `tree-sitter-cli` exists (the `tree-sitter`
      port is the library only) and is now in the Portlist.
- [ ] **tmux `prefix + r` touches the wrong `tmp/restart.txt`.** `run-shell` runs in the tmux
      server's cwd. Use `run-shell -c '#{pane_current_path}' 'touch tmp/restart.txt'`.
- [ ] **`bootstrap.sh` overwrites `/etc/hosts`.** The repo copy carries BuyaPowa entries and
      the copy wipes the `kubernetes.docker.internal` line Docker Desktop adds.
- [ ] **`git/.gitCommitTemplate` is 0 bytes** but `commit.template` points at it. Fill or remove.
- [ ] **Hammerspoon README drift.** Lists Hyper+E (VPN) which no longer exists; omits
      Hyper+Alt+M (unminimise); `pomodoor.lua` is not required by `init.lua` although
      AGENTS.md says pomodoro is part of the config.

## 2. Decisions

- [ ] **Sign commits with SSH instead of GPG.** `gpg.format = ssh`,
      `user.signingkey = ~/.ssh/id_ed25519.pub`, `gpg.ssh.allowedSignersFile` for local
      verification, and upload each machine's public key to GitHub as a *signing* key.
      Removes `gnupg/`, `pinentry-mac`, `GPG_TTY` and the Keychain-prompt saga (ssh-agent
      already uses Keychain). Also fixes a latent bug: `.personal-gitconfig` hard-codes
      `BDEE812945109695`, the key generated on *this* laptop today (uid says "2015 Macbook
      Pro"), so the file cannot be shared with the work laptop. The pub key *path* is the same
      on both machines.
- [ ] **Drop fisher.** Vendored 3.2.8 (2019); fisher 4 uses `fish_plugins`, not `fishfile`.
      The only package is docker completions, which `docker completion fish` now provides.
      Also delete the fisher leftovers `docker.fish` and `docker-compose.fish` in
      `~/.config/fish/functions` (not symlinks, from 2021).
- [ ] **Stop forcing `TERM` in `config.fish`.** `set -x TERM tmux-256color` applies to every
      shell including outside tmux; Ghostty wants `xterm-ghostty`, the iTerm2 profile says
      `xterm-256color`, and the italic terminfo compiled by `iterm2/setup.sh` is never used.
      Let the terminal set TERM (tmux already sets its own inside), and add
      `set -as terminal-features ",xterm-ghostty:RGB"` in `.tmux.conf`. macOS 12 ships
      `tmux-256color`, so the iterm2 terminfo files can probably go.
- [ ] **`ut_aws.sh` is zsh and edits `~/.zshrc`** but the login shell is fish. Port the `a`
      profile switcher to a fish function (`set -gx AWS_PROFILE`) or delete it.
- [ ] **Curate `macos/setup.sh`.** Still mostly the original author's list.
      `AppleLanguages -array "en" "nl" "tr"` is currently applied on this Mac;
      `persistent-apps -array` empties the Dock every run; `LSQuarantine false` disables
      Gatekeeper's download warning; many trackpad/Finder keys are no-ops on recent macOS.
      A hand-picked ~20 lines you understand beats 340 you don't.
- [ ] **Trim `.gitignore_global`.** `build/`, `*.map`, `*.d`, `*.a`, `*.so`, `*.lib` etc. will
      hide legitimate files in some repos. Keep OS/editor noise and
      `**/.claude/settings.local.json`; language ignores belong in each repo.
- [ ] **Is VS Code still in use?** `settings.json` hard-codes `/Users/tbaynes/...` kube tool
      paths and six `/var/folders/.../postman-*` temp files, points fish at
      `/opt/homebrew/bin/fish`, uses removed settings (`python.linting.*`,
      `terminal.integrated.rendererType`), and enables Copilot settings next to
      `chat.disableAIFeatures: true`. Prune or drop the folder.
- [ ] **Casks on the MacPorts Mac.** brew is installed here with casks only (alfred,
      claude-code, docker-desktop, google-drive, hammerspoon, zoom) but `packages/setup.sh`
      skips the Brewfile entirely when MacPorts is present. Option: when MacPorts is primary,
      run `brew bundle` on a filtered Brewfile (`grep -E '^(tap|cask|mas) '`). Also:
      `claude-code` cask is declared nowhere; `brew "postgresql"` now floats to
      `postgresql@18`, pin if it matters.
- [ ] **master vs main.** `init.defaultBranch = main`, but the `prm` alias and the `grbi`,
      `grbm`, `grbom` abbreviations hard-code `master`. Consider `origin/HEAD` / `@{upstream}`.

## 3. Robustness and maintainability

- [ ] **Shebangs lie.** Scripts declare `#!/usr/bin/env sh` but use `[[ ]]`, `local`, `<<<`,
      `&>` and `=~`. They only work because macOS `/bin/sh` is bash 3.2. Declare bash
      everywhere (`macos/setup.sh` already does).
- [ ] **`symlink()` in `scripts/functions.sh` does `rm -r` on the destination**, including a
      real directory such as a pre-existing `~/.config/nvim`. Move aside to `*.bak` instead.
- [ ] **Bootstrap order is filesystem order** (`find *`). Use an explicit list so dependencies
      are visible, and add a one-line guard at the top of app-specific scripts
      (`[ -d /Applications/Ghostty.app ] || exit 0` for ghostty, iterm2, vscode, hammerspoon).
      `xcode-select --install` returns before the GUI install finishes, so the success
      message is wrong.
- [ ] **Dead code in `packages/setup.sh`.** The `*.list` loop has nothing to iterate. The
      Portlist header says names are unverified; everything on it except `mas` and
      `terraform-1.17` is installed here and both of those are real ports (`mas @7.0.0`,
      `terraform-1.17 @1.17.2`). Verified names for the commented block: `py313-awscli`,
      `kubectl-1.37`, `postgresql16`/`17`, `fnm` or `nvm` for node.
- [ ] **Fish abbreviations.** `setup` is a generic function name that is easy to collide with.
      Since fish 3.6 abbrs are per-session, so the `abbr -e` loop and `fish -c setup` in
      `fish/setup.sh` do nothing lasting. Idiomatic home: `conf.d/abbreviations.fish`
      (symlink the `conf.d` dir too). Also: every fish file has a `#!/usr/local/bin/fish`
      shebang that is wrong on both machines (drop, or `#!/usr/bin/env fish`); `abbrex` is
      unused and broken under fish 4's `abbr` output format; `emptytrash` clears ASL logs that
      no longer exist; `completions/bundle.fish` and `gem.fish` are 2019 copies shadowing
      fish's built-ins; the universal `fish_user_abbreviations` var in `fish_variables` still
      carries asdf entries (`set -eU fish_user_abbreviations`); mix of
      `set -g fish_user_paths` and `fish_add_path`, pick one.
- [ ] **nvim: `<leader>s` (nearest spec) is a prefix of `<leader>ss` (spell)**, so running the
      nearest spec waits out the 500 ms timeout. Rename one.
- [ ] **nvim, smaller.** `williamboman/mason*` moved to `mason-org/` (redirects today).
      ruby_lsp via mason uses whichever Ruby is on PATH, which can mismatch rbenv-pinned
      projects. Trailing-whitespace autocmd matches `*.*` only: Makefile/Dockerfile skipped,
      Markdown hard line breaks stripped. `init.vim` could be `init.lua`.
- [ ] **tmux nits.** `status-right` spawns `date` every refresh; tmux formats do strftime:
      `set -g status-right " %a, %b %d - %I:%M "`. Reload message says "RELOADEDAD". The
      commented-out copy-mode block is pre-2.4 syntax; modern form:
      `bind -T copy-mode-vi v send -X begin-selection`,
      `bind -T copy-mode-vi y send -X copy-pipe-and-cancel pbcopy` (no reattach-to-user-namespace).
- [ ] **`claude/statusline.sh`** runs jq four times per refresh; one `jq -r '[..] | @tsv'` call
      would do.
- [ ] **README is from 2016.** Ruby-based Homebrew installer, "from the original author" blog
      links, customisation notes pointing at a `[user]` block and a computer name that are no
      longer where it says.
- [ ] **Local cleanup (this machine).** `~/.vimrc` and the three `~/bin` links are dangling.
      `~/.tmux.conf`, `~/.config/nvim`, `~/.hammerspoon/*` and the VS Code link are owned by
      root (something was run with sudo on 14 Nov); the scripts call sudo themselves, so run
      them as the user.
- [ ] **AGENTS.md drift.** `bin/` destination and `bak`; iterm2 row implies the plist is
      installed; hammerspoon row mentions pomodoro.
