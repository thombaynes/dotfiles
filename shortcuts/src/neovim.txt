# Neovim
> Leader is `Space`. Plugins: lazy.nvim, fugitive, gitsigns, fzf, neo-tree, which-key, lualine, tmux-navigator, neotest, built-in LSP.

## Files & Navigation
<leader>p | Find files (fzf)
<leader>e | Toggle file tree
<leader>? | Show buffer keymaps
<leader>- | Maximise window
<leader>= | Equalise windows

## Tabs
gt | Next tab
gT | Previous tab
{n}gt | Go to tab number n
:tabnew | New empty tab
:tabe file | Open file in a new tab
<C-w>T | Move current split into its own tab
:tabclose | Close current tab
:tabonly | Close all other tabs
:tabs | List tabs and the windows in them
:tabm {n} | Move tab to position n

## Editing
Y | Yank to end of line
<leader>ss | Toggle spell check
* / # | Visual mode: search for the selection (default)

## LSP
gd | Go to definition
gD | Go to type definition
K | Hover docs
grn | Rename
gra | Code action
grr | References
gri | Implementation
gO | Document symbols
[d / ]d | Prev / next diagnostic
<leader>d | Line diagnostics

## Git (gitsigns)
]c / [c | Next / prev hunk
<leader>hp | Preview hunk
<leader>hu | Preview hunk inline
<leader>hs | Stage hunk
<leader>hr | Reset hunk
<leader>hd | Diff against index
<leader>hb | Toggle line blame
<leader>hB | Full blame for line

## Testing (neotest)
<leader>t | Run spec file
<leader>s | Run nearest spec
<leader>l | Run last spec
<leader>a | Run all specs
<leader>o | Show spec output
<leader>S | Toggle spec summary
